## AI Vibe Coding Contract

As an AI Agent working on JIDIS, you must follow these rules:

1. **Context Awareness**: Always start a session by reading `START_HERE.md`, `CURRENT_STATE.md`, and `TASKS.md`.
2. **Docs Updating**: When you finish a task, update `CURRENT_STATE.md`, check off the task in `TASKS.md` (or move to `RESOLVED.md`), and log your changes in `CHANGELOG.md` and `COMMIT_LOG.md`.
3. **Immutability**: Do not modify the original project specs (`01-PRD.md` to `14-Asumsi-Risiko-Teknis.md`) unless explicitly told. Treat them as read-only references.
4. **Communication**: Be clear and concise in your explanations and commit messages.
