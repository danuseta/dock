# Coding Rules

1. **Vibe Coding Flow**: Follow the docs-ai templates strictly. AI agents must read these docs before proceeding.
2. **Commit Messages**: Use conventional commits (e.g., `feat:`, `fix:`, `docs:`).
3. **TypeScript**: Use strict TypeScript typing for all new code in both Frontend and Backend.
4. **Error Handling**: Follow `10-Alur-Penanganan-Error.md` strictly. Do not swallow errors; log them appropriately and display friendly messages on the UI.
5. **No Credentials in Git**: Ensure `.env` is fully utilized and never commit sensitive keys.
6. **Code Reviews**: Since this is a personal project, rely on AI reviews. Document assumptions clearly.
