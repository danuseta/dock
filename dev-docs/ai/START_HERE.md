# Start Here

## Welcome to JIDIS Development

This document serves as the entry point for all developers and AI agents working on the JIDIS project.

## Directory Structure
- `dev-docs/ai/`: Contains all AI vibe coding documentation.
- `apps/`: Will contain the frontend and backend applications (Electron + BFF).

## Workflows
1. Always read `TASKS.md` for current active tasks.
2. Update `CURRENT_STATE.md` before finishing a session.
3. If new issues arise, document them in `KNOWN_ISSUES.md`.
4. Follow `CODING_RULES.md` for all development.

## Tech Stack Overview
- **Electron**: For Windows desktop wrapper.
- **React/Vite**: Frontend UI.
- **Node.js/GraphQL**: BFF layer.
- **TailwindCSS**: Styling (assumed).

For detailed architecture, see the PRD and architecture specs in the root directory.
