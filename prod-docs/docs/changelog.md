## [1.0.0] - 2026-07-30
### Added
- Initial production release.
- Web application interface (React).
- Desktop application interface (Electron).
- BFF GraphQL API Gateway.
- Auth Service (JWT based authentication).
- Data Service (Core business logic).
- PostgreSQL database schema and migrations.
- Docker Compose configuration for local dev and production.
- Comprehensive documentation suite.

### Security
- Integrated HashiCorp Vault for secrets management.
- Enforced TLS 1.3 across all endpoints.
