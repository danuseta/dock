JIDIS UI proposal · Home + Navigation

A calmer Home, with navigation that follows the way you work.

This proposal does not change the React application yet. Every mode below is interactive: left or right sidebar and top or bottom floating dock. Collapse applies only to sidebars because both docks are already compact.

Recommended default: expanded left sidebar. Home uses a compact clock, four metrics in one strip, icon-only Quick Links, a monthly calendar, Current Work, and Service Health. The runtime panel is removed, and the sidebar footer shows only the version. On narrow screens, navigation becomes a floating dock.

System Settings / Interface

Navigation placement

Choose the primary navigation position. The preference is stored per browser.

Sidebar behavior

Applies only to the left or right sidebar.

Trade-offs across four modes

All four modes can be available, but one default keeps the experience consistent across devices.

Recommended

Left sidebar

Labels remain visible, the pattern is familiar, and it can collapse to 72px. This is the best desktop default.

Right sidebar

The reading area starts cleanly from the left. It works well when controls and focus stay on the right.

Floating top

Provides maximum board width through an icon dock that floats away from the top edge and stays centered.

Floating bottom

The cleanest option for mobile. On desktop it relies on icons and tooltips, so discovery is slightly weaker.
